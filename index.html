Help & shortcuts

Shortcuts

  • Tab — new test / restart lesson (fresh words)
  • Esc — restart the same words / lesson
  • ↵ — next test (on the results screen)

Modes

  • time — type as long as the clock runs. Great for score graphs.
  • words — a fixed set of words that ends automatically on the last word.
  • quote — type a full quote with attribution.
  • custom — paste your own text and practice on exactly that.

Difficulty

  • beginner — the most common, shortest words — great for new typists.
  • easy — everyday short words.
  • medium — everyday but longer words.
  • hard — advanced vocabulary.
  • expert — rare, long, technical words. Brace yourself.

Typing aids

  • next-word suggestions — the upcoming words appear under the text while you type; turn off in settings if you prefer a clean screen.
  • on-screen keyboard — highlights exactly which key comes next, including Shift combos.

Scoring

  • WPM — correct characters ÷ 5, scaled to one minute.
  • Raw — every character you typed (incl. mistakes).
  • Accuracy — correct ÷ all typed characters.
  • Consistency — how steady your pace was across seconds.

Tips

  • Keep wrists up and fingers anchored on the home row.
  • Accuracy first: at 95%+ accuracy, speed follows almost free.
  • Finish a run before correcting — count on the backspace sparingly.
  • Use the Practice tab until each row is automatic.

Custom text

Paste any text — a paragraph, code snippet, homework — and practice on exactly that. The test ends when you finish it.
